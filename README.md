# Chad Gys — Portfolio

A responsive Vue 3 portfolio built with Vite and Vue Router.

## Getting started

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Structure

- `src/components` — shared site header and footer
- `src/views` — Home, About, Skills, and Contact routes
- `src/main.js` — app entry point
- `src/router` — Vue Router configuration
- `src/assets` — shared stylesheet and static assets
- `src/App.vue` — top-level app component
- `vite.config.js` — Vite tooling configuration
- `package.json` / `package-lock.json` — dependencies and scripts
